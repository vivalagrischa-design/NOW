# NOW App 0.4.1

Premium dating / meetup prototype centered on real intent + real availability.

## Quick preview
```bash
npm install
npx expo start --web
```

The web preview is intentionally rendered in a centered mobile frame so it can be judged like an app rather than a full-width website.

See `DESIGN_NOTES.md` for the visual changes and `UI_REFERENCE.png` for the intended look.
